# Лабораторная: веб-приложение «Прибывалка» для электричек


## Что сделано

1. **Поиск станции по строке**.
2. **Карта**
3. **Расписание по станции**
4. **Маршрут A → B**
5. **Избранное**
6. **Сервер** 
7. **Тема**



В `.env` (из `.env.example`): `YANDEX_API_KEY`, при необходимости `SERVER_PORT` (по умолчанию 3001).

```bash
npm install
npm start
```
